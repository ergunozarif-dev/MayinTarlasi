# Mayin Tarlasi Oyunu

C# winforms kullanarak yaptıgım basit bi mayin tarlası projesi. Klasik oyunu kendi çapımda biraz deniyerek ve eglenceli olsun diye emojiler ekleyerek kodladım.

## Özellikler
- Dinamik satır sütun ve mayin ayarı yapılabiliyo.
- Sag click ile bayrak koyulabiliyor.
- Mayına basınca üzgün surat emojisine dönüyo.
- Kutular acıldıkca etraftaki bomba sayısını gosteriyo.
